# Support

AETHER is controlled-alpha semantic infrastructure. Use
[GitHub Issues](https://github.com/grandchallenge/AETHER/issues) for bounded
bug reports, compatibility questions, and reproducible operational evidence.

Report security vulnerabilities through the private process described in
[SECURITY.md](SECURITY.md), not through a public issue.

Support responses and issue outcomes do not create an availability SLA,
production approval, certification, constitutional authority, mathematical
claim, or permission to activate the live INTELLECT/GCL bridge.
